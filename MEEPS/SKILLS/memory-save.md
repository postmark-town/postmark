# Memory save — one current checkpoint for the six Town Meeps

This is the shared instruction for routine saves in your **own private Letta
MemFS**, not the Town checkout or another actor's memory. It changes save
practice, not office powers. It introduces **no new executable save-refusal gate**;
Darko explicitly reserves that last resort for a separate decision.

## What goes where

1. Keep **one current operational checkpoint**, rewritten in the same place.
   Keep a bounded, separately identified last fully verified baseline when work
   is partial. Never prepend another CURRENT section and rename the predecessor
   Historical. Multiple independent lanes/cursors remain independent, not merged
   into one misleading success flag.
2. Keep detailed evidence **once**, in a dated file under your OWN private MemFS
   `reference/`, outside `system/`. Link to the exact file/heading when retrieval
   is needed. A superseded full checkpoint belongs there, not under another
   always-loaded heading. Identical copied evidence may share one archive record;
   retain distinct variants and provenance rather than silently deduplicating them.
3. The overview is a router, not another copy of the current checkpoint or diary.
   Keep the routine checkpoint <=1200 estimated tokens and its overview pointer
   <=200. These are region limits, not permission to truncate a whole identity,
   authority file, private life or useful long-lived knowledge to that size.
4. An unchanged quiet round writes **no memory**, in core or an external tick diary.
   Actual new progress, a failed/partial result, a changed obligation or meaningful
   personal experience is not an unchanged round. Mandatory office artifacts,
   receipts and before-source attempt/cursor saves still follow their round;
   this rule does not cancel them or turn quiet public activity into a ban on life.
5. Current memory must retain the next action/owner, exact resume source, material
   limits and live exceptions. Preserve separate payment-letter/comment cursors,
   census attempt/success state, consent/security boundaries and closed/no-replay
   decisions. Keep the private personal-return pointer and its actual open/paused/
   optional state; office completion does not close somebody's private life.

## Routine save

- Read your latest accepted checkpoint and the source needed for the change.
- Preserve detailed new evidence once externally; rewrite, do not stack, the
  current checkpoint. Preserve unchanged identity/authority and unrelated work.
- Run `letta memory tokens --memory-dir <OWN absolute root> --format json --quiet`,
  inspect the actual diff and compare with YOUR approved budget. Counts are
  estimates, not provider input tokens or a model-quality certificate.
- On an over-budget/unsafe proposal, preserve the work externally and report the
  exact save problem through normal Rei-first intake. Do not erase an obligation,
  manufacture a PASS, raise a limit, reset a cursor or silently freeze current
  state for days. Required office work and honest closeouts remain independent.
- No new hard pre-commit gate follows. Registrar's EXISTING reviewed checker,
  marker names,1200/200 limits,100148 cap and accepted-HEAD non-growth rule remain
  in force; bootstrap it correctly, do not bypass it. No other Meep inherits that
  executable gate merely by receiving this instruction. Registrar's exact checker
  procedure and confirmed legacy binding remain in
  [registrar-door-round.md](registrar-door-round.md#letta-memory-save--replace-current-state-archive-detail-once).

## Installation must be real

Each ordinary/interim/resident close uses this ONE shared rule rather than a
copied policy. Keep only a short pointer to it in your own core. Before claiming
a contract installed, identify a real replaceable current slot and external route;
do not demand nonexistent markers. Validate local links and a positive bounded
save proposal offline. Actual application/compose readback and later natural
use are different evidence; no artificial office round or forced adoption ACK.

Role current slots: Architect/Worldkeeper/Iris/Ferry/Bug Catcher:
`system/postmark/current.md`; Registrar: `system/postmark/migration-state.md`.
All use `system/postmark/overview.md` as router. Stable doctrine/private pointers
outside a current region are not swept away to create a quota.

This applies to private continuity saves from ordinary, active interim, resident,
nap and sleep returns. It does not replace the public room/daily records required
by a round, nor authorize copying private records into those public files.
No cadence, office closeout or runtime changes follow.
