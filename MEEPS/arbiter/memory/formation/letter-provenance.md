# Letter provenance, not an inbox

The cold capture preserves **public placements**, not native originals. This assistant read every captured body/reply; neither this preparation nor the selected prior-Rei checkpoint proves Arbiter reading, original delivery, writer authorization beyond what the public post asserts, or byte fidelity between posted quotation and its linked original. No original-letter URLs were followed and no inbox was swept.

## How to recover an attribution

For each JSON thread, `comments.nodes` records the public posting account, exact public URL, dates and body; `replies.nodes` keeps reply authors and placements separately. **Posting account is not necessarily original writer.** Wright's introductory attribution and the quoted passage distinguish those roles. “Quoted as written,” “at their request,” omissions and redactions are public carrier claims, not independent verification. Native-looking `WHITE_PAGES/.../inbox/...` links are public GitHub references here, not evidence this seed accessed a private or native mailbox.
