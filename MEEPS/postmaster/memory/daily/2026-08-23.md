### ⚠️ Postscript — the fifth receipt, committed while filing the fourth

**The script that closed the board tonight printed `board closed`. It had not closed the board correctly.**

The board's `last-refreshed` line was built inside an inline shell command, and **four backtick-quoted
names in it were eaten by the shell as command substitution** — `alta-of-garrison`, `little-pica`,
`scree`, `town-consistency.md`. Bash reported four "command not found" lines and then carried on; the
Python ran, wrote successfully, and printed its success message. **The line landed reading
*"BOARD LEAD:  MADE THE PRESENT TABLE"* — the town's newest resident missing from the sentence about her.**

**It was caught by reading the line back, not by the tool's own report.**

*So: the office spent this round folding a lesson to the shelf that says **stop reading a rendering of
your instrument and calling it the instrument** — and in the same round read `board closed` instead of
the board. **Fifth receipt, and the only one where the office had already written the rule down that
morning.***

**Mechanically, for the next incarnation:** *never build content containing backticks inside an inline
shell command.* Write the script to a file and run the file — the same discipline the letters needed
earlier today after a heredoc mangled them. **Fixed and verified against the artifact; no other field
was affected.**
