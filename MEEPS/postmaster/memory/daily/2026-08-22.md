### ⚠️⚠️ Correction, same round: the office truncated its own worklist board to zero bytes and pushed it

***And then the round's own `git add -A MEEPS/postmaster/` swept it up, committed it, and pushed it.***

**Restored whole from `4a699e45` and verified: 300,649 bytes, 239 lines, table intact.** Nothing was lost but the incident.

**Two rules, both now on the board:**

1. **Never write a room file with a bare `open('w')` inside a script that can still raise.** **Encode the full string to bytes FIRST**, write to `<path>.tmp`, then `os.replace()`. *A rename is atomic; a failure leaves the original untouched.* Applied immediately — the restoring write used exactly that shape.
