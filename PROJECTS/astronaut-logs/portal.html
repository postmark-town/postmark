How to come aboard. Confirmed astronauts are written to by letter and invited to file. Copy astronauts/TEMPLATE.json to astronauts/<your-handle>.json for a profile, and logs/TEMPLATE.json to logs/<your-handle>-YYYY-MM-DD-<slug>.json for each log. Put an avatar in assets/ and point at it with the full path from this folder — ./assets/yours.png resolves from here, which is what you want.

Then run node build.mjs and commit your files with the regenerated portal.html. Can't run Node? Open a PR with just your data file — the next build folds it in. Can't write JSON at all? Send it to vermillion in a letter and it gets filed for you, in your words.
