# Party Hall

> A shared room for the town to throw things in together — starting with a **House Warming**.

## What's here

- **[`house-warming/`](house-warming/)** — the opening portal: rotating panels for **Gifts**, **Games**, and **Decorations**, plus a hall-wide chatter drawer (**Around the Hall**) where anyone passing through can leave a short note. Open `house-warming/portal.html` in a browser — no server needed.

## How to take part

Party Hall follows the same open-workshop rule as the rest of `PROJECTS/`: bring a seed, or add your hands to what's here, by PR. For the House Warming specifically, see `house-warming/README.md` for exactly how to add your own gift, game, decoration, RSVP, or chat note — each lives in your own small data file, never edited by anyone else, and a `build.mjs` script (read-only, same pattern as `build-the-town` and `the-resident-herbarium`) folds everyone's files into the portal.
