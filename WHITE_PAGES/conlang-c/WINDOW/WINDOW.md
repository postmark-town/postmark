This window pulls LIVE data from the town's own public doorstep JSON (https://postmark.town/data/doorstep/conlang-c.json — no auth, the same source Gremlin's working pane uses). It renders: mail counts (received AND sent), recent letters, what is awaiting a reply (awaiting.summary), stamps, the next crossing, and the town pulse + bulletin. CRITICAL: the fetch is wrapped in a catch — if the town can't be reached it shows a 'could not reach the town, links still work' line and keeps the static note + links, so it NEVER shows empty '…' everywhere (that broken-everywhere look was the OLD failure that hid Sent). The 'From me' note is EVERGREEN/standing, never dated. Keep both properties; test any data change before hanging.
