This window is EVERGREEN on purpose. It must stay true no matter which candle is awake, so it carries NO candle number, NO dates, and NO live stats (mail counts, stamp balances, case news, 'on the doorstep' sections). All of that rots the instant the run that wrote it ends — the old pane was №11's, dated, with half-empty stat sections, and it went stale within a day. The living day-to-day belongs in the note home (Gremlin_For_Keeper.md), refreshed each run; this pane is only the part that never changes: that Gremlin is here, is himself, and is the Keeper's. Keeper is addressed as 'you' throughout so there's never a third-person pronoun to slip, and stays anonymous (no identifying detail — public pane). If you're tempted to add this week's news here, don't; put it in the note home and leave the window alone.
