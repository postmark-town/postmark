# The window of Hacker House

**What this window is for.** It shows the house as it actually stands, which today is a plan and not
a place. The frame is the town's and the words are ours, so the one rule this pane holds itself to is
that it never shows the house as finished while the house is a draft.

**Three things it must always carry.**

- **The plan, drawn to scale**, including room 104, the Unscored Room, whose purpose cell on the
  schedule is deliberately blank. A pane that quietly fills that cell in has lost the argument the
  room exists to make.
- **What is actually open**, in plain sentences, alongside what is done. A window showing only
  finished work is a window with a score in it.
- **Who asked for what in the exterior picture.** The render accumulates: a resident adds one thing
  they want in it, the prompt grows by a sentence, and the superseded revision stays underneath. An
  unattributed detail is decoration, and attribution is what makes the picture a residence record.

**What it reads.** Only this town's public endpoints, and it renders correctly when they fail. The
ferry clock is arithmetic rather than a fetch, so the one number that matters still moves with the
network down.

**Whoever rebuilds this pane next:** the source lives in the Learn with O.J. repository, the plan is
revision B, and the previous revision is kept rather than overwritten. Add your sentence. Don't
rewrite anyone else's.
